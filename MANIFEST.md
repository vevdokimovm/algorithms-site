# Манифест репы `algorithms-site`

## 1. Что это за репа — в трёх предложениях

Пет-проект: обучающий сайт по алгоритмам в формате «теория → визуализация → где ломается →
задача с проверкой», один HTML-файл без сборки и сервера. Не претендует на отличие от
существующих ресурсов (e-maxx объясняет, площадки проверяют — здесь одно место делает оба),
это решение автора записано явно. От `algorithms` (личная база решений и конспектов)
отличается тем, что это публикуемый продукт с интерфейсом, а не личные заметки.

**Класс:** `product`
**Видимость:** приватная (пет-проект, не выложен публично на момент манифеста)
**Версия на момент манифеста:** 1.0.0 (MVP)

## 2. Описание для `.repo-meta` и GitHub

```
Обучающий сайт по алгоритмам: теория → интерактивная визуализация → типичные ошибки →
задача с автопроверкой. Один HTML-файл, без сборки и сервера. MVP: урок «Бинарный поиск».
```

**Теги:** `algorithms, education, interactive, single-file, javascript, mvp, pet-project`

## 4. Классификация: что сюда идёт, а что нет

**Сюда идёт:** уроки в установленном формате (идея → визуализация → где ломается →
задача с проверкой), сам код сайта.

**Сюда НЕ идёт — и куда вместо:**

| Что | Куда | Почему не сюда |
|---|---|---|
| личные решения задач Codeforces/LeetCode без продуктовой формы | `algorithms` | это конспект, не публикуемый урок |
| подготовка к интервью | `algorithms` / `career` | другой жанр материала |

**Названный вслух потолок (не пограничный случай, а честная граница возможностей):**
проверка задачи — не настоящий Python, а его подмножество, транслированное в JS
(`def/if/elif/else/while/for...in range`, множественное присваивание, `//`, `len`,
`and/or/not`); закрывается только переходом на Pyodide (`ROADMAP.md` P2). Транслятор
чинился трижды на ложно-зелёных тестах — сейчас есть канарейка (заведомо неверное решение
обязано падать).
