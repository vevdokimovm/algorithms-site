## [1.0.0] — 2026-08-21 — MVP: один урок целиком как образец формата (MINOR)

Уровень `1.0.0` по `base-repo/00-infrastructure/83-project-maturity-levels.md` §3:
сквозной сценарий (открыл → прочитал → решил → проверился) работает целиком,
запуск двойным щелчком, потолок назван.

### Added
- Урок «Бинарный поиск» в формате **идея → визуализация → где ломается → задача**.
- Интерактивная визуализация: границы `lo`/`hi`, середина, пошагово или целиком,
  с числом выброшенных элементов на каждом шаге.
- Разбор трёх мест, где алгоритм ломается: переполнение `(lo+hi)/2`, несогласованный
  инвариант границ, зависание.
- Задача `lower_bound` с проверкой на 8 тестах, включая дубликаты и пустой массив.

### Fixed — три бага транслятора, и ни один не поймал тест
- Регулярка не закрывала блоки: в Python они закрываются **отступом**. Переписано
  на подсчёт отступов.
- `var` на каждом присваивании → переобъявление внутри цикла.
- `//` заменялось на `/`, и `a[1.5]` в JS молча возвращал `undefined`.
  **Все тесты при этом проходили — случайно.** Поймано чтением вывода глазами.
- Добавлена канарейка: заведомо неверное решение обязано падать, и оно падает.

### Известные ограничения
- Проверка исполняет **подмножество** Python, транслированное в JS, а не Python.
  Настоящая проверка требует Pyodide или судьи на сервере.
- Урок один. Это образец формата, а не ресурс. Критерий выхода в `2.0.0` — десять уроков.
