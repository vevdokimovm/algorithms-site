## [1.2.3] — 2026-08-29 — README приведён к стандарту 98 (PATCH)

### README приведён к стандарту `98-readme-standard.md`

Стандарт заведён 29.08.2026 по требованию владельца: *«сделай стандарт README
на основе того, как он сделан у `personal-finance-dss` — там самый подробный —
и сделай у всех других по этому стандарту подробный README»*.

🔴 **Прямо копировать образец нельзя**, и это главное в стандарте: у базы
знаний нет API и быстрого старта. Замер подтвердил различие — `product`
в среднем **165 строк**, `satellite` **69**. Разница не в небрежности:
у продукта больше того, что надо рассказать.

Поэтому общий скелет из семи разделов + разделы по классу репы.

**Что добавлено сборщиком `rebuild_readme.py`** — всё **из написанного
человеком**, ничего не сочинено:

- **«С чего начать»** — только существующие файлы, в порядке чтения;
- **«Что здесь можно узнать»** — из **заголовков документов**: заголовок
  и есть вопрос, на который документ отвечает;
- **«Границы — чего здесь НЕТ»** — предложения `MANIFEST.md` §1 с отрицанием;
- **таблица структуры** — столбец «что внутри по существу» берётся
  из `MANIFEST.md` §3, иначе из заголовков файлов, иначе пишется честно,
  что описания нет.

Прежняя таблица «Repository map» с **пустым столбцом Contents** снята —
это и была та «херня с таблицей», о которой говорил владелец.

**По системе:** медиана README **56 → 77 строк**, у баз знаний 61 → 84.

## [1.0.0] — 2026-08-21 — MVP: один урок целиком как образец формата (MINOR)

Уровень `1.0.0` по `base-repo/00-infrastructure/83-project-maturity-levels.md` §3:
сквозной сценарий (открыл → прочитал → решил → проверился) работает целиком,
запуск двойным щелчком, потолок назван.

### Added
- Урок «Бинарный поиск» в формате **идея → визуализация → где ломается → задача**.
- Интерактивная визуализация: границы `lo`/`hi`, середина, пошагово или целиком,
  с числом выброшенных элементов на каждом шаге.
- Разбор трёх мест, где алгоритм ломается: переполнение `(lo+hi)/2`, несогласованный
  инвариант границ, зависание.
- Задача `lower_bound` с проверкой на 8 тестах, включая дубликаты и пустой массив.

### Fixed — три бага транслятора, и ни один не поймал тест
- Регулярка не закрывала блоки: в Python они закрываются **отступом**. Переписано
  на подсчёт отступов.
- `var` на каждом присваивании → переобъявление внутри цикла.
- `//` заменялось на `/`, и `a[1.5]` в JS молча возвращал `undefined`.
  **Все тесты при этом проходили — случайно.** Поймано чтением вывода глазами.
- Добавлена канарейка: заведомо неверное решение обязано падать, и оно падает.

### Известные ограничения
- Проверка исполняет **подмножество** Python, транслированное в JS, а не Python.
  Настоящая проверка требует Pyodide или судьи на сервере.
- Урок один. Это образец формата, а не ресурс. Критерий выхода в `2.0.0` — десять уроков.
