Сайт по алгоритмам: **теория → визуализация → где ломается → задача с проверкой**.

Тот ресурс, которого не хватало в школьные годы: e-maxx объяснял, но не показывал
и не проверял; площадки с задачами проверяли, но не объясняли. Здесь одно место.

**Пет-проект, не продукт.** Отличаться от существующих ресурсов не пытается —
это решение автора, записанное явно, чтобы к нему не возвращаться.

## Запуск

```
open index.html
```

Ни сборки, ни сервера, ни зависимостей. Один файл, открывается двойным щелчком.

## Что внутри — MVP на одном уроке

Урок «Бинарный поиск» сделан **целиком**, чтобы задать формат для остальных:

1. **Идея** — с ответом «что это даёт руками» (20 шагов вместо миллиона).
2. **Визуализация** — интерактивная: массив, границы `lo`/`hi`, середина, пошагово
   или целиком. Видно, как область поиска уполовинивается, и сколько элементов
   выброшено на каждом шаге.
3. **Где ломается** — три места: переполнение `(lo+hi)/2`, несогласованный инвариант
   границ (таблица `[lo,hi)` против `[lo,hi]`), зависание.
4. **Задача с проверкой** — `lower_bound`, 8 тестов включая дубликаты и пустой массив,
   с кнопкой «показать решение» и разбором ключевой строки.

## Уровень зрелости

`1.0.0` — MVP по `base-repo/00-infrastructure/83-project-maturity-levels.md` §3.
Один сквозной сценарий (открыл → прочитал → решил → проверился) работает целиком.

**Критерий выхода в `2.0.0`, записанный заранее:** десять уроков в этом же формате
и оглавление, по которому видно порядок прохождения. Один урок — это образец формата,
десять — уже ресурс.

## 🔴 Потолок, названный вслух

- **Проверка задачи исполняет не Python, а его подмножество, транслированное в JS.**
  Поддерживается: `def`/`if`/`elif`/`else`/`while`/`for ... in range`, множественное
  присваивание, `//`, `len`, `and`/`or`/`not`. Всё остальное не разберётся.
  Настоящая проверка требует Pyodide или судьи на сервере — в MVP этого нет.
- **Транслятор чинился трижды, и все три раза ловил не тест, а разбор вывода глазами:**
  регулярка не закрывала блоки (в Python они закрываются отступом) · `var` на каждом
  присваивании давал переобъявление в цикле · `//` заменялось на `/`, и `a[1.5]`
  молча возвращал `undefined` — **тесты при этом проходили случайно**.
  Сейчас есть канарейка: заведомо неверное решение обязано падать, и оно падает.
- **Уроков один.** Это образец формата, а не ресурс.
